# 浏览器授权

本插件使用 HTTP Remote MCP 与 OAuth 授权码流程 客户端读取服务端元数据 注册自身回调地址 使用 PKCE S256 打开拓元登录和授权页面

用户用自己的拓元账户登录 确认应用和权限后返回助手 客户端接收并保存授权 不需要用户创建或复制 Access Key

Codex 安装后新建任务 在 MCP 连接管理中登录 tuoyuanai Claude Code 安装后在 MCP 管理中完成同一授权 其他支持 HTTP MCP 的客户端可添加 https://tuoyuanai.com/mcp

授权过期时重新连接 个人中心的已连接助手可随时断开授权 已完成的项目与媒体不会删除

当前仓库为 1.0.0-rc.1 平台必须同步部署本次 Remote MCP 与授权接口 仓库更新不代表生产接口已经上线 本地验收地址使用完整 Compose 环境对应的 /mcp

此前已配置的脚本凭据和平台历史项目不在此次升级中删除 新安装一律使用客户端浏览器授权 不再引导用户创建密钥
